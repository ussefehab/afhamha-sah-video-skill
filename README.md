# سكيل فيديوهات «افهمها صح»

دي السكيل اللي Claude بيستخدمها عشان يعمل فيديو ريلز ٩:١٦ كامل بالمصري: سكريبت، وصوت مصري، وانيميشن، وترجمة كلمة بكلمة، ومزيكا ومؤثرات متألفة بالكود، وفي الآخر ملف MP4. كل ده بيتعمل على جهازك ومن غير برامج مونتاج.

## التركيب

1. نزّل Claude Desktop من claude.ai/download وافتح تبويب Code.
2. حط الفولدر ده (`egyptian-promo-video`) جوه:
   - ويندوز: `C:\Users\<اسمك>\.claude\skills\`
   - ماك: `~/.claude/skills/`
3. افتح محادثة جديدة في Code واكتب مثلًا:
   «اعملي فيديو ريلز بالمصري عن [موضوعك] أو [موقعك]».
   Claude هيقرا السكيل لوحده ويمشي على خطواتها.

## هتحتاج

- Node.js وFFmpeg وGoogle Chrome. لو مش عندك، اطلب من Claude يثبّتهم.
- مفتاح مجاني للصوت من aistudio.google.com/apikey. هتحطه بنفسك في ملف `.env` جوه فولدر الفيديو، ومتبعتهوش لحد.

## ملاحظات

- الحد المجاني للصوت المصري حوالي ١٠ طلبات في اليوم، وClaude بيسجّل السكريبت كله في طلب واحد.
- القالب الجاهز معمول لإعلان سيستم طلبات مطعم. غيّر المشاهد والألوان لمنتجك أو موضوعك، والمحرك هو هو.
- اقرا `references/gotchas.md`، فيه كل مشكلة قابلتنا وحلها.

لو عملت فيديو بالسكيل دي ابعتهولي أشوفه 🙌
